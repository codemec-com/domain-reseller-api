# Changelog

## 1.0.0 – 2026-10-09

- First public version of the Cloudzaro Domain Reseller API
- Availability check, holder contacts, domain registration and transfer, order status
- Auto-renew and holder change, auth code
- DNS records (A, AAAA, CNAME, MX, TXT, SRV, CAA, NS) and DNSSEC on/off
- OpenAPI 3.0 specification and examples for curl, PHP, Node.js and Python
